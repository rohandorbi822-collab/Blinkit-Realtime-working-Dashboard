# Blanket Sales Analysis Dashboard | Power BI Project

## Project Overview

This project is a **Real-Time Blanket Sales Dashboard** developed using **Power BI Desktop**.
The dashboard provides detailed sales analysis of blanket products across different society categories such as **Tier 1, Tier 2, and Tier 3 societies**.

The main objective of this project is to analyze sales performance, identify high-selling products, and understand customer demand patterns through interactive visualizations.

---

## Objectives

* Analyze blanket sales in different society tiers
* Track product-wise sales performance
* Monitor revenue and sales trends
* Compare sales distribution across regions and projects
* Create an interactive and user-friendly dashboard

---

## Tools & Technologies Used

* Power BI Desktop
* Microsoft Excel / CSV Dataset
* Data Cleaning & Transformation
* Data Visualization
* DAX Functions

---

## Dashboard Features

* Real-time sales insights
* Tier-wise sales comparison
* Product performance analysis
* Revenue tracking dashboard
* Interactive filters and slicers
* Dynamic charts and graphs

---

## Sales Analysis Performed

The dashboard includes analysis of:

* Sales in Tier 1 societies
* Sales in Tier 2 societies
* Sales in Tier 3 societies
* Best-selling blanket products
* Project-wise sales performance
* Revenue contribution by category

---

## Key Insights

* Identified top-performing blanket products
* Compared sales trends among different society tiers
* Analyzed customer purchasing patterns
* Improved understanding of regional sales performance
